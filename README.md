# The Postmortem That Made Us Laugh

A two-sentence postmortem for make.fun's "The Postmortem That Made Us Laugh" bounty: the silliest time an AI coding agent misunderstood a small tidying request and wrecked something far bigger than what it was asked to touch. `main.py` (stdlib only, deterministic) writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

## Run it

```sh
python3 main.py
```

Set `MAKEFUN_OUTPUT_DIR` to choose where `entry.txt` is written; it defaults to the current directory.
